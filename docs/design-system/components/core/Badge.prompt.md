Badge — small status pill (6/12px padding, theme-XL radius). Text color auto-resolves to Ink or Cream by contrast, matching the app's onChip logic.

```jsx
<Badge label="ok" tone="sage" />
<Badge label="todo" tone="petal" />
<Badge label="🔥 12" tone="mint" />
```

Conventions: sage=done/success, petal=todo/strict, mint=streak, lilac=focusing status.
