SoftCard — the app's single card primitive: Surface or Cloud fill, 1px Mist hairline, theme-large radius, 20px padding, whisper shadow (light mode only).

```jsx
<SoftCard tone="cloud"><p>emergency unlock</p></SoftCard>
<SoftCard onClick={open}>pressable row card</SoftCard>
```

Radius follows the active theme: 28px kawaii, 10px tough, 12px neutral.
