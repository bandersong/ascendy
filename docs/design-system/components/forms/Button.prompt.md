Button — Material-3-shaped pill in Petal; 'text' variant matches Compose TextButton. Disabled dims to 40%; pressing scales to 0.97.

```jsx
<Button onClick={save}>save</Button>
<Button variant="text" onClick={cancel}>nevermind</Button>
<Button disabled>use unlock</Button>
```

In Tough scopes the label auto-uppercases via the theme's heading transform.
