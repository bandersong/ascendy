Privacy Policy

Effective: 2026-05-16. Last updated: 2026-06-02.

Short version

Ascendy collects no personal data. All app and website blocking happens entirely on your device. Nothing is transmitted, shared, sold, or stored on any server we control. We do not use analytics, crash reporting, or any third-party SDKs.

Permissions, and what each is used for

Accessibility service
Used to detect which app is in the foreground during a focus session, and to read the URL bar in known browsers to block specified websites. The service inspects only the currently-active window and only while a session is active. It does not log, transmit, or persist any window content.
VpnService
Used during a session to run a local DNS sinkhole — DNS queries for domains you've blocked are answered with NXDOMAIN; all other queries are forwarded to a public upstream resolver (Cloudflare, 1.1.1.1). No traffic is intercepted, logged, or sent to any server we control. The tunnel runs entirely on-device. It is automatically stopped when your focus session ends.
Device administrator
Optional. Only activated when you enable Lockdown mode in settings. Prevents Ascendy from being uninstalled while a focus session is active. Automatically deactivated when no session is running. You can disable it at any time in Settings > Security > Device admin apps when outside a session.
Usage access
Fallback path for foreground-app detection when the accessibility service is unavailable (for example, Android 17 Advanced Protection Mode). Queries are run on-device and not persisted.
Display over other apps
Used to display the "session active" overlay over a blocked app while a session is in progress.
Notifications
An ongoing notification is shown while a focus session is active, per Android foreground-service requirements.
NFC
Read/write NTAG21x stickers to identify your physical anchor. We read or write only the small UUID payload described above.
Camera
Used only when you tap the in-app "scan QR" button, to decode a QR code locally. No frames or images are stored or transmitted.
Schedule exact alarms
Used to fire scheduled focus sessions and pomodoro auto-end at the exact times you configure.
Battery exemption (Ignore Battery Optimizations)
Optional. Improves the reliability of background blocking on aggressive OEM battery managers (Samsung, Xiaomi, OnePlus). No data effect.
Query all packages
Used to populate the in-app picker that lets you choose which installed apps to block.
Request install packages (sideload / F-Droid builds only)
Used by the in-app updater to install a newer Ascendy APK downloaded from GitHub Releases. The Play Store build of Ascendy does not include the in-app updater and does not request this permission.

Third parties

Ascendy contains no third-party advertising SDKs, analytics SDKs, crash-reporting SDKs, or social-login SDKs. Apart from the optional DNS forwarding above (which routes only standard DNS queries to a public resolver) and the optional in-app updater (which fetches release metadata and an APK file from GitHub when you tap "Check for updates"), Ascendy does not make any outbound network connections.

Children

Ascendy is not directed at children under 13. Because we collect no personal information, no special handling is required.

Changes to this policy

Any change to data handling will be published on this page with a new "Last updated" date and called out in the release notes.
